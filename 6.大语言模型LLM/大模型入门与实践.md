#### 4.构建专属对话助手-openwebui

Anaconda安装与配置

```
官网：https://www.anaconda.com/download#downloads

配置环境变量（按照自己的安装路径进行配置即可）
D:\software\anaconda\install
D:\software\anaconda\install\Scripts
D:\software\anaconda\install\Library\bin
D:\software\anaconda\install\Library\mingw-w64\bin
```

创建虚拟环境

```
创建深度学习环境并命名为chatglm3，指定python版本为3.11:
conda create --name chatglm3 python=3.11

Anaconda激活chatglm3环境:
conda activate chatglm3

Anaconda退出激活环境:
conda deactivate

```

安装openwebui，设置访问地址以及端口

```
openwebui官方网址：https://www.openwebui.com/

Anaconda激活chatglm3环境:
conda activate chatglm3

安装open-webui
pip install open-webui

启动open-webui服务
open-webui serve
```

#### 5.构建专属对话助手-maxkb

```
1.打开官网：
https://maxkb.cn/docs/installation/online_installtion/

2.在命令行中执行命令，运行容器
docker run -d --name=maxkb --restart=always -p 4000:8080 -v ~/.maxkb:/var/lib/postgresql/data -v ~/.python-packages:/opt/maxkb/app/sandbox/python-packages registry.fit2cloud.com/maxkb/maxkb

3.待所有容器状态显示为healthy后，可通过浏览器访问 MaxKB：
http://目标服务器 IP 地址:4000

默认登录信息
用户名：admin
默认密码：MaxKB@123..

4.进入后即可修改密码


5.在应用中设置AI模型即可使用
```

#### 6.构建专属对话助手-dify

```
1.下载安装包
GitHub地址：https://github.com/langgenius/dify

2.解压
unzip dify-main.zip

3.docker-compose安装dify
cd dify-main
cd docker
cp .env.example .env
docker compose up -d
```
